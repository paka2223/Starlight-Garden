# 별빛 정원

Godot 4.7용 오리지널 육성 시뮬레이션 프로토타입입니다. 시작할 때 아이의 이름과 생년월일을 입력합니다. 별자리 운세에 따라 초기 능력치와 특정 활동의 성장 보너스가 달라집니다. 10살부터 18살까지 매달 생활 계획을 세우고, 학업·일·모험·휴식의 균형을 잡습니다.

## 실행

Godot 4.7에서 `project.godot`을 열고 `Main.tscn`을 실행하세요.

## 플레이

- 매달 교육, 아르바이트, 훈련, 모험, 휴식 중 하나를 선택합니다.
- 선택에 따라 능력치, 스트레스, 건강, 생활비와 자금이 바뀝니다.
- 사건은 능력치와 선택한 생활 방식에 영향을 받아 결과가 달라집니다.
- 별의 탑 던전은 지식과 마력으로 봉인을 풀며 층을 오르고, 금화와 별가루를 모읍니다. 층이 깊어질수록 더 높은 탐험력이 필요합니다.
- 18살이 되면 성장 과정에 따라 직업과 엔딩이 정해집니다.
- `저장`과 `불러오기`로 진행 상황을 보관할 수 있습니다.

## 이미지

`assets/harin.svg`의 임시 픽셀 캐릭터와 `assets/dungeon.svg`의 던전 표식을 사용합니다. 게임용 아트로 교체하기 쉽도록 SVG 자산을 별도 폴더에 두었습니다.

## 구조

```text
res://
├── Main.tscn
├── assets/           # 임시 픽셀 캐릭터와 던전 아이콘
└── scripts/game.gd   # 프로필, 달력, 성장, 던전, 엔딩, 저장 및 UI
```
